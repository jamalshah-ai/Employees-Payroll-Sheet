# Employee Payroll Sheet

## Project Overview

This project uses **Microsoft Excel** to manage employee payroll and salary information.

It includes employee departments, basic salary, allowances, deductions, gross salary, net salary, payment status, employment type, and payroll dates.

## Features

* Employee salary tracking
* Gross salary calculation
* Deduction tracking
* Net salary calculation
* Payment status tracking
* Department-wise payroll data
* Full-Time, Part-Time, and Contract employees
* Payroll date tracking

## Tools Used

* Microsoft Excel
* Excel Formulas
* Sorting & Filtering
* Data Validation
* Charts

## Note

All data used in this project is **dummy data created for learning and portfolio purposes**.
